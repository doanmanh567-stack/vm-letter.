# V/M LETTER v1.3.2 PWA

Giải nén ZIP, tải thư mục vm22-premium (chứa index.html trực tiếp) vào Deploys của website Netlify hiện tại. Mở địa chỉ HTTPS trong Safari, Chia sẻ > Thêm vào màn hình chính > Thêm. Bật Mở dưới dạng ứng dụng web nếu có. Mở app từ icon. Chế độ ngoại tuyến cần truy cập online lần đầu và service worker cài thành công; iOS có thể thu hồi bộ nhớ. Lưu ảnh qua menu chia sẻ tùy khả năng iOS. Không phải IPA.
